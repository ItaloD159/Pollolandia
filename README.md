Pollolandia es un sistema de consola desarrollado en Python que busca simular la administración de ventas y el funcionamiento de una caja registradora en una pollería.
Este sistema aplica el paradigma de la Programación Orientada a Objetos (POO) a través de la interacción entre diversas clases (Persona, Empleado, Cliente, Entrega, Pedido, Metodo_Pago y Sistema_Caja). Las operaciones que permite llevar a cabo son las siguientes:
-Inicio de Sesión: Autenticación básica del cajero por medio de un código de acceso.
-Menú interactivo: Elección de platos, combos y bebidas, con el cálculo del subtotal al instante.
-Tipos de entrega: Administración del consumo en salón (vinculado a un número de mesa) o delivery (con un recargo automático por envío y la dirección correspondiente).
-Emisión de comprobantes: Registro de los datos del cliente para generar la boleta (DNI) o la factura (RUC).
-Gestión de pago: Comprobación del monto recibido, cálculo del vuelto exacto y verificación de pagos insuficientes.
-Flujo continuo: Posibilidad de ingresar varios pedidos dentro de una misma sesión de caja.
